# Nova — Bilingual Business & Agency Template (Arabic / English)

Thank you for your purchase!

## What's included
- `index.html` — the full template (one file: HTML + CSS + JavaScript, no frameworks, no build step)
- Arabic + English with a one-click switch (full RTL / LTR)
- Light and dark mode
- Sections: hero with rotating words, logo marquee, services, about with counters, 4-step process,
  portfolio with filters and popup, testimonials slider, pricing (monthly / yearly), FAQ, call to action, contact form, footer
- Animations: scroll reveal, counters, floating shapes, 3D tilt, mouse glow, progress bar, back-to-top
- Fully responsive (phone, tablet, desktop) and respects "reduce motion" settings

## How to edit
1. Open `index.html` in any text editor (Notepad, VS Code...).
2. **Colours:** at the top of the `<style>` section, change `--primary`, `--primary-2` and `--accent`.
3. **Texts:** at the top of the `<script>` section, every text is written as `["English", "Arabic"]`. Change the words between the quotes.
4. **Services, projects, testimonials, pricing, FAQ:** edit the lists `SVC_TXT`, `WORKS`, `QUOTES`, `PLANS`, `FAQ` in the same script.
5. **Default language:** open the page with `?lang=ar` for Arabic, or change `let L = ... ? 1 : 0` to `let L = 1`.
6. Upload the file to any hosting (or GitHub Pages / Netlify) — it works as-is.

## Contact form
The form shows a thank-you message. To receive emails, connect it to a free service such as Formspree
(add `action="https://formspree.io/f/YOUR-ID" method="POST"` to the `<form>` and remove the `onsubmit` line).
